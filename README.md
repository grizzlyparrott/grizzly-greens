# Grizzly Greens

Grizzly Greens is a lawn care and outdoor maintenance education website built with custom HTML, CSS, and JavaScript.

The site focuses on lawn basics, soil and fertilizer, watering and irrigation, weeds and pests, tool safety, and practical yard maintenance. It is built as a real public content site, not a demo project.

Live site: https://grizzlygreens.net/

## What this project demonstrates

This project demonstrates my ability to build and maintain a structured static website with organized content sections, internal linking, SEO-focused pages, and responsive layouts.

Key work includes:

- Custom HTML and CSS pages
- Responsive page layouts
- Organized article hubs and category folders
- Internal linking between related pages
- SEO-focused page titles, metadata, and structure
- Sitemap generation
- Search index generation
- Ongoing site updates and content expansion
